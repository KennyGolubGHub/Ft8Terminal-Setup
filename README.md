# FT8 Terminal for Windows

**Download the installer only.** Do not use GitHub's "Source code" zip or tar.gz links - those are not the program.

[Download FT8 Terminal 1.1.0](https://github.com/KennyGolubGHub/Ft8Terminal-Setup/releases/download/v1.1.0/Ft8Terminal-Setup-1.1.0.zip)

1. Unzip the file.
2. Run **Ft8Terminal-Setup.exe**.
3. The program installs for the current Windows user. Leave the default folder, or choose another folder that account can write to. Settings and the ADIF log are saved there.
4. On the new PC, open **Settings** and enter your callsign, grid, radio, and audio devices. This setup does not copy those from another computer.
5. Uninstalling removes the program and leaves `settings.json` and `ft8.log.adi` in the install folder.

Windows 10 or Windows 11, 64-bit. The .NET runtime is included. No separate runtime install is required.

This page is a download location. The application source is not published here.

Windows may warn that the app is unrecognized because it is not code-signed.
